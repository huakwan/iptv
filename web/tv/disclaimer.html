ข้อจำกัดความรับผิด

เว็บไซต์นี้ทำหน้าที่เป็นเพียงผู้รวบรวมและแสดงลิงก์สตรีมที่เผยแพร่ต่อสาธารณะ โดยไม่ได้โฮสต์ จัดเก็บ หรือดัดแปลงเนื้อหาวิดีโอใด ๆ ด้วยตนเอง

ลิขสิทธิ์และเครื่องหมายการค้า

  • เนื้อหารายการ ชื่อ โลโก้ และเครื่องหมายการค้าของแต่ละช่อง เป็นทรัพย์สินของเจ้าของลิขสิทธิ์นั้น ๆ
  • เว็บไซต์นี้ไม่มีส่วนเกี่ยวข้อง ได้รับการสนับสนุน หรือได้รับการรับรองจากสถานีโทรทัศน์หรือผู้ถือลิขสิทธิ์ใด
  • หากแหล่งลิงก์ต้นทางปิดหรือหยุดเผยแพร่ ช่องนั้นจะไม่สามารถรับชมได้

คำขอให้ลบเนื้อหา

หากท่านเป็นเจ้าของลิขสิทธิ์และต้องการให้ลบลิงก์ที่เกี่ยวข้อง กรุณาแจ้งผ่าน GitHub Issues พร้อมรายละเอียดลิงก์ที่ต้องการให้ดำเนินการ เราจะตรวจสอบและลบออกโดยเร็วที่สุด

การใช้งาน

ผู้ใช้ควรใช้เว็บไซต์นี้เพื่อการรับชมส่วนบุคคลเท่านั้น และเป็นความรับผิดชอบของผู้ใช้เองในการปฏิบัติตาม กฎหมายและข้อกำหนดที่เกี่ยวข้องในเขตพื้นที่ของตน
